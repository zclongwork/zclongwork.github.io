先把重要的问题说清楚

常见问题

轻量不意味着含糊。关于安装、数据和当前边界，你可以在这里得到直接答案。

还有问题？前往 GitHub 提问 ↗
需要注册账号或保持联网吗？

不需要。应用没有账号或后端，也未申请网络权限。待办默认保存在设备本地。

卸载应用后，数据还在吗？

应用私有数据会随卸载清除。你可以提前授权一个外部文件夹开启自动备份；备份文件可在卸载后保留，重新安装后再手动选择文件恢复。

备份文件经过加密吗？

当前没有加密，文件中可能包含待办标题，请只选择可信的位置。应用只访问你通过系统文件选择器授权的目录，不会申请整张存储设备的权限。

支持提醒、云同步或多人协作吗？

当前不支持按事项时间提醒、云同步和多人协作。25 分钟专注在自然结束时可以发送提醒，但不会自动勾选事项。

如何安装每日待办？

首个公开版本将优先通过 GitHub 提供。你可以先访问项目仓库查看源码、更新记录和后续发布。

支持哪些 Android 设备？

应用支持 Android 6.0（API 23）及以上。应用内请求添加桌面小部件需要 Android 8.0 及以上，并取决于当前桌面是否支持。
